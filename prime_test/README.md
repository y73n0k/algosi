# Вероятностные тесты на простоту.

В файлах [fermat.py](fermat.py), [solovey_shtrassen.py](solovey_shtrassen.py), [miller_rabin.py](miller_rabin.py) представлены реализации алгоритмов Ферма, Соловея-Штрассена и Миллера-Рабина.

В файле [jacobi_symbol.py](jacobi_symbol.py) представлен алгоритм для нахождения символа Якоби для теста Соловея-Штрассена.

В [test.py](test.py) представлены примеры использования алгоритмов.

Запуск программы:

```bash
python test.py
```
